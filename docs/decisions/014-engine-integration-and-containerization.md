# Decision 014: Analysis Engine Integration and Containerization

## Status
Accepted

## Context
`docs/ARCHITECTURE.md` Sections 3 and 4 and Prompt 5.8 require the complete integration of the offline forensic pipeline into a production CLI (`smscope analyze`), elimination of all stub fixtures, packaging into a deterministic container image pinned by cryptographic digest, and establishment of committed golden test baselines.

## Decisions

1. **End-to-End Pipeline Wiring**:
   - Replaced all stub fixtures with real forensic dataflow:
     1. **`ingest`**: Reads raw PCAP packets, validates packet headers, performs bidirectional TCP stream reassembly via sequence tracking, and computes `pcapSha256`. Raises `EmptyCaptureError` (exit code 2) if no valid streams exist.
     2. **`process_protocols`**: Performs content-based protocol identification (`identify`) and runs protocol-specific state tracking (`track_smtp`). Attaches streams to `SessionRecord`s.
     3. **`process_tls`**: Parses TLS record layer and handshake messages (`parse_tls_handshake`), negotiates cipher parameters and key exchange, and computes JA3/JA3S fingerprints (`negotiate_tls`).
     4. **`process_certs`**: Evaluates observable X.509 certificate chains (`analyze_certificate_chain`) against capture timestamps and local CA trust store anchors (`client_trust.crt`).
     5. **`evaluate_rules`**: Evaluates all 12 Tier 1 detection rules, deduplicates findings per `(ruleId, serverEndpoint)`, and caps evidence at $\le 5$ entries.
     6. **`process_results`**: Computes pure integer host scores and letter grades, packages findings and scores into a deterministic Merkle tree, and writes canonical JSON artifacts.

2. **Container Packaging**:
   - **Base Image**: Pinned by cryptographic digest `python:3.11-slim-bookworm@sha256:7f4d22197ae71221f7db19eb0b1f4806a143b879c5dc2ab440056e4c76b1f237`.
   - **Non-Root Execution**: Runs under unprivileged user `engineuser` (`uid 1000`).
   - **Pinned Dependencies**: `dpkt==1.9.8`, `cryptography==48.0.0`, `jsonschema==4.25.1`, `pyyaml==6.0.2`.
   - **Execution Policy**: Container is invoked with `--network none` and `--read-only` root filesystem mounting a writable output directory.
   - **Entrypoint**: `ENTRYPOINT ["python", "-m", "smscope"]`.

3. **Golden Baseline Outputs**:
   - Committed baseline outputs for all 17 lab scenarios (`S01a` to `S13`, `X01` to `X03`) located in `tests/golden/<SCENARIO>/`.
   - Generated by `scripts/make_golden.py` using canonical serialization.
   - Continuous validation enforced by `engine/tests/test_golden.py` comparing fresh analysis outputs byte-for-byte and hash-for-hash against committed goldens.

4. **Multi-Run Determinism Verification**:
   - Verified via `scripts/determinism_check.sh` and `scripts/determinism_check.py` running the engine twice per capture and confirming zero SHA-256 differences.

## Consequences
- Milestone M2 (Analysis Engine) is fully reached with zero stub dependencies.
- Independent validator nodes can execute the identical containerized engine without network access and produce matching Merkle roots.
- Guarantees byte-for-byte reproducibility of all forensic analysis outputs.
