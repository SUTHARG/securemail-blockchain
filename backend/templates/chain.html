⚙️ Network Configuration & Remix Deployment Guide (Click to expand)

1. Setting up Local Hardhat Network in MetaMask

To connect MetaMask to your local node, add a custom network in MetaMask settings:

  • Network Name: Hardhat Local
  • New RPC URL: http://127.0.0.1:8545
  • Chain ID: 31337
  • Currency Symbol: ETH

2. How to Point SecureMailScope to Remix or Other Testnets

If you deployed your contracts via Remix (e.g. to Sepolia or a custom chain), you do not need to rewrite source code. Update your deployment file without overwriting local configurations:

  1. Create or edit your deployment JSON file (e.g., contracts/deployments/remix.json) with the deployed addresses, chain ID, and network name.
  2. In your .env file, set: 
    DEPLOYMENT_FILE=contracts/deployments/remix.json
RPC_URL=https://sepolia.infura.io/v3/YOUR_KEY
  3. Restart the backend server. The app and MetaMask inspector will automatically load the new contract addresses and chain ID without any manual code changes.
